# Fonts

The site is set up for four licensed typefaces. Add the `.woff2` files here with
these exact names and they load automatically. Until then, the site uses close
free fallbacks from Google Fonts.

| Role | Family | Files expected |
|---|---|---|
| Hero headline | Couture | `Couture-Bold.woff2` |
| Titles | PolySans | `PolySans-Neutral.woff2`, `PolySans-Median.woff2`, `PolySans-Bulky.woff2` |
| Body text | Peridot | `Peridot-Regular.woff2`, `Peridot-Medium.woff2`, `Peridot-SemiBold.woff2` |
| Labels and captions | Quartz | `Quartz-Regular.woff2`, `Quartz-Medium.woff2` |

Only upload fonts you hold a web licence for.
